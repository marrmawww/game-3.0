
 Навигация по папкам
- 01_Core — Base, GameController, Logger.
- 02_Units — Unit, характеристики, девять типов юнитов и фабрики.
- 03_Terrain — типы ландшафта, карта и Proxy.
- 04_NeutralObjects — сундук, ловушка, алтарь, источник энергии и Strategy.
- 05_LR3/Buildings — лечебница как новое здание.
- 05_LR3/Systems — UnitManager, ResourceSystem, CombatSystem, BuildingManager, GameMediator.
- 05_LR3/Commands — отдельные классы команд.
- 05_LR3/Facade — GameFacade.
- 05_LR3/Handlers — цепочка обработки пользовательского ввода.
- 06_Run — main.cpp, интерактивный запуск
